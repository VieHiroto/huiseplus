# 飲食店内部管理アプリ（GAS + スプレッドシート + スマレジ）

## ファイル構成

```
├── appsscript.json       GASマニフェスト
├── Code.gs               メインルーター（doGet）
├── SpreadsheetSetup.gs   スプレッドシート初期化
├── SmaregiAPI.gs         スマレジAPI連携
├── BusinessStatus.gs     営業状況管理
├── MenuManager.gs        メイン・おばんざい管理
├── SalesReport.gs        売上レポート
├── HandoverSheet.gs      引き継ぎシート
├── Customer.html         お客様表示画面
└── Staff.html            スタッフ管理画面
```

## セットアップ手順

### 1. スプレッドシートにGASを紐付け
1. Googleスプレッドシートを新規作成
2. 拡張機能 → Apps Script を開く
3. 上記の `.gs` / `.html` / `appsscript.json` をコピー＆ペースト

### 2. スマレジ設定を入力
`SmaregiAPI.gs` の以下を自分の情報に書き換える
```javascript
var SMAREGI_CONFIG = {
  CONTRACT_ID: 'YOUR_CONTRACT_ID',   // ← スマレジ契約ID
  ACCESS_TOKEN: 'YOUR_ACCESS_TOKEN', // ← アクセストークン
};
```

### 3. スプレッドシートを初期化
GASエディタから `setupSpreadsheet` 関数を手動実行
→ 6つのシートが自動作成されます

### 4. Webアプリとしてデプロイ
1. デプロイ → 新しいデプロイ → Webアプリ
2. 実行者：自分、アクセス：全員（匿名含む）
3. URLをコピー

### 5. 画面アクセス
| 画面 | URL |
|------|-----|
| お客様表示 | `デプロイURL?page=customer` |
| スタッフ管理 | `デプロイURL?page=staff` |

## スプレッドシート シート一覧

| シート名 | 用途 |
|---------|------|
| 営業時間管理 | 通常/特別営業時間・待ち状況 |
| メニュー管理 | 本日のメイン・おばんざい |
| 引き継ぎ_メニュー | 残数・仕込み管理 |
| 引き継ぎ_通常 | 通常引き継ぎ記録 |
| 日売上 | 日別売上（スマレジから自動取得） |
| 月売上 | 月別日次売上 |

## 営業ステータス

| ステータス | お客様画面 |
|-----------|-----------|
| 通常営業 | 営業時間を表示 |
| 貸切 | 「本日貸切」 |
| 臨時休業 | 「本日休業」 |
| 特別時間 | 設定した時間を表示 |

待ち時間 > 0分 の場合は「約○分お待ち」と表示されます。
